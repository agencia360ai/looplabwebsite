# App Screens

Drop product screenshots here as PNGs (transparent bg or matching the app
theme) using the filenames the code references. The Lab section will swap from
mascot-only to screenshot-led for any project that has its file present.

| Filename                | Used in                  |
| ----------------------- | ------------------------ |
| `taekwondo-home.png`    | Lab → taekwondo card     |
| `boxing-home.png`       | Lab → boxing card        |
| `chef-home.png`         | Lab → chef card          |

Recommended: portrait phone aspect (9:19.5 or 9:16), ~1080×2340 PNG. The card
crops to a 3:4 viewport so anything taller than that gets the bottom clipped
(intended — it shows the "top of phone" feel).
